脚本中的双语文本：`game` 运行时 i18n API 与 DSL `@t` 语法。

## 开始前

阅读[场景 DSL 参考](../reference/dsl/scene.md)了解 `@speaker` / `@option` / `@t` 的摆
放规则，阅读 [GUI DSL 参考](../reference/dsl/gui.md)了解 `.gui` 文件中的 `@t`。

## 概述

通过 DSL（`@run { ... }` 块、`.scene`）编写或手写 JS 编写的脚本使用 `game` 全局对象
与游戏引擎交互。下面的 i18n API 支持多语言。

## API

### `game.lang()`

以字符串形式返回当前语言。

| 返回值 | 语言 |
|-------------|----------|
| `"en"`      | 英语 |
| `"zh"`      | 中文 |

```js
if (game.lang() === "zh") {
    await game.showText("你好！");
} else {
    await game.showText("Hello!");
}
```

### `game.t(en, zh)`

根据 `game.lang()` 选择合适的字符串。语言为英语时返回 `en`，为中文时返回 `zh`。

```js
await game.showText(game.t(
    "Hello! Welcome to the world of monsters!",
    "你好！欢迎来到怪物的世界！"
));
```

### DSL `@t("en", "zh")`（`.scene` / `.gui` 首选）

用 DSL 而非手写 JS 编写时，把文本包在 `@t("English", "中文")` 里。在 `.scene` 文件中
它可用于 `@speaker` 行和 `@option` 标签，并编译成上面的 `game.t(en, zh)` 调用；在
`.gui` 文件中它可用于 `text(...)` / `button(...)`，并编译成按 locale 区分的
`{"en": …}` / `{"zh": …}` 键值对，由渲染器按语言解析。

```
game_scene Example {
    @storylines {
        @speaker("") {
            @t("Hello! Welcome to the world of monsters!", "你好！欢迎来到怪物的世界！")
        }
        @choice {
            @option(@t("YES", "是")) {
                @speaker("") { @t("You chose YES!", "你选了是！") }
            }
            @option(@t("NO", "否")) {
                @speaker("") { @t("You chose NO.", "你选了否。") }
            }
        }
    }
}
```

## 示例

### 对话示例

```js
export async function talkTravelerF() {
    await game.showText(game.t(
        "It's rumored that\nlittle sprites came\nfrom the moon!",
        "据说小精灵是从\n月亮来的！"
    ));
}
```

### 选项对话

```js
export async function talkMuseumVisitor() {
    await game.showText(game.t(
        "Did you check out the MUSEUM?", "你去博物馆看过了吗？"
    ));
    const choice = await game.showChoice([
        game.t("YES", "是"), game.t("NO", "否")
    ]);

    if (choice === 0) {
        await game.showText(game.t(
            "Weren't those fossils amazing?",
            "那些化石是不是很棒？"
        ));
    }
}
```

### 条件逻辑

```js
export async function talkSign() {
    if (game.lang() === "zh") {
        await game.showText("前方森林\n请小心！");
    } else {
        await game.showText("THE FOREST AHEAD\nBe careful!");
    }
}
```

## 重要提示

- 所有新脚本都应使用 `game.t()` 处理双语文本。
- `\n` 用于单次 `showText` 调用内的换行。
- 游戏引擎不会裁剪文本——为获得最佳显示效果，每行约 15 个 CJK 字符或约 30 个 ASCII
  字符换一次行。
