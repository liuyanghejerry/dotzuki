# 编辑关联建筑与连接墙体

> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.6.0
>

在地图中复用像素素材，并根据相邻格选择墙角。

开始前，请阅读[地图指南](./maps.zh-CN.md)，并在[项目清单](../reference/project-manifest.md)
中配置 map 和 tiles 活动。

## 放置和更新建筑

1. 打开 **地图** 并选择地图，双击建筑缩略图编辑像素。
2. 保存建筑。PNG 和可编辑图层附属文件保存在共享图块目录中。
3. 选择可见图层，启用 **关联建筑**，在地图上盖章放置建筑。
4. 再次编辑并保存该建筑，点击地图工具栏的 **更新组件**。
5. 保存地图；其他使用同一建筑的地图需要分别执行更新。

[linked component](../reference/glossary.md#map-components)（关联组件）在地图图层中记录
源 ID、版本、位置、原有格子和覆盖格子。更新保留位置；源像素变透明时恢复原有格子。
工具栏报告更新和跳过的数量。源尺寸改变、源缺失或覆盖范围被外部修改时，需要检查对应实例，
更新操作不会覆盖这些实例。

普通图块绘制会解除覆盖该格的组件关联。盖章前关闭 **关联建筑** 可放置独立副本。
撤销和重做同时恢复像素与关联；更新操作为每个发生变化的图层生成一个撤销记录。
调整地图尺寸会让关联随格子移动，超出新边界的组件会解除关联。

此功能加入前放置的建筑保持独立，需要重新以关联方式放置。

## 绘制连接墙体

为一种墙体材质制作十六个非空的 1×1 建筑组件，统一厚度、轮廓和光照方向。
在共享图块目录创建 `connections.json`，内容如下，并将各组 ID 换成素材的 ID。

```json
{
  "version": 1,
  "sets": [{
    "id": "plaster",
    "name": "Plaster walls",
    "variants": {
      "0": "wall-island", "1": "wall-n", "2": "wall-e", "3": "wall-ne",
      "4": "wall-s", "5": "wall-ns", "6": "wall-es", "7": "wall-nes",
      "8": "wall-w", "9": "wall-nw", "10": "wall-ew", "11": "wall-new",
      "12": "wall-sw", "13": "wall-nsw", "14": "wall-esw", "15": "wall-cross"
    }
  }]
}
```

[connection mask](../reference/glossary.md#map-components)（连接掩码）取北=1、东=2、南=4、
西=8 的和。例如东西连接使用 10，孤立格使用 0。不同规则组、不同图层之间不相连。

重新加载编辑器，选择 **墙体** 和规则组，在可见图层上拖动。左键添加墙体，右键删除墙体并
恢复下方格子。每笔结束后，相邻墙体自动选择转角、交叉口和端头。撤销恢复整笔操作。
删除墙体时请在 **墙体** 工具中右键拖动，让相邻端头一起更新。

墙体笔刷编辑可见格子。请在对应碰撞图层标记墙体阻挡，并让门洞格子保持可通行。
墙立面和门板作为独立关联建筑放置。

## 保留导入的图集素材

建筑盖章和组件更新保留原有 GID，直接从地图的 `tileset.png` 复制旧像素，
不要求共享素材库包含旧图块的 PNG。缺失列数时从图片宽度推算，新组件格子追加到图集。

如果图集和引用的共享图块都不存在，准备操作会在写文件前报告错误；恢复图片后重试。
地图保存和撤销影响地图格子，追加的图集位置在撤销后仍保留，编辑器不会压缩未使用位置。

素材备份和源格式请参阅[素材指南](./assets.zh-CN.md)。
