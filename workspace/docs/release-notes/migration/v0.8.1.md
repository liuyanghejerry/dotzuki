# Migrating to v0.8.1

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.8.1

Update every `dotzuki-*` dependency from v0.8.0 to v0.8.1. This release has
no breaking Rust API changes.

Before you start, read the [changelog](../changelog.md) for this patch's
scope.

## Update dependencies

Keep all engine crates on one version. For registry dependencies:

```toml
dotzuki-engine = "0.8.1"
dotzuki-mobile = "0.8.1"
```

For git dependencies, update every engine entry to `tag = "v0.8.1"`, then
run:

```bash
cargo update
```

## Re-export mobile hosts

`dotzuki export --android` and `dotzuki export --harmony` now write launcher
icons: adaptive icons for Android, and a layered icon plus a start-window mark
for HarmonyOS. A host exported before v0.8.1 keeps whatever icons it was
generated with, so re-run the export and rebuild the app to pick them up. The
template ships a neutral mark; replace the layer bitmaps after export when a
game needs its own art.
