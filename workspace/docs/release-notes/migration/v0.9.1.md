# Migrating to v0.9.1

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.9.1

Update from v0.9.0 to adopt the shared landscape touch controls without changing Rust APIs.
Before you start, read the [changelog](../changelog.md) for the release scope.

## Update dependencies

Update every dotzuki dependency together: use version `0.9.1` for registry dependencies
or tag `v0.9.1` for git dependencies, then refresh the consumer lockfile.
The minimum Rust version remains 1.88.

## Refresh Android and HarmonyOS shells

Back up custom host changes before regenerating an export. Follow the
[Android](../../how-to/export-android.md) or
[HarmonyOS](../../how-to/export-harmonyos.md) export guide.
The new hosts use the full game surface with overlaid controls and support both landscape
orientations. They retain the existing eight input bits and mobile ABI version 1.

Use the gear to adjust size, position, opacity, side swapping, floating movement, and haptics.
Settings persist separately from saves. Check the default and mirrored layouts against your
game's dialogue and choice menus: the generic ABI does not expose menu bounds, so choice
menus can still overlap controls.

## Integrate iOS controls

Add the reusable UIKit package using the
[shared touch integration guide](../../../crates/dotzuki-mobile/controls/README.md).
The consuming game still owns its iOS shell, rendering, audio, and lifecycle.
Read `consumeInput()` once per game tick and combine it with hardware input; pause gameplay
while editing controls and release touch input when the scene loses focus.
This release does not add an iOS exporter.

## Verify the consumer

Exercise movement plus A/B, quick taps, both landscape orientations, background/foreground
transitions, and settings persistence. Validate safe areas and dialogue clearance on target
devices. CI covers shared input logic and UIKit simulator integration; device-specific
behavior still needs testing on the consuming game's supported hardware.
