将所有 `dotzuki-*` 依赖从 v0.8.0 更新到 v0.8.1。本版本没有破坏性的 Rust API
变更。

开始前，请阅读本补丁适用范围的[变更日志](../changelog.zh-CN.md)。

## 更新依赖

所有引擎 crate 应使用同一个版本。使用 registry 依赖时：

```toml
dotzuki-engine = "0.8.1"
dotzuki-mobile = "0.8.1"
```

使用 git 依赖时，把每个引擎依赖更新为 `tag = "v0.8.1"`，然后运行：

```bash
cargo update
```

## 重新导出移动端宿主

`dotzuki export --android` 与 `dotzuki export --harmony` 现在会写出启动图标：安卓
使用自适应图标，鸿蒙使用分层图标加启动页图标。在 v0.8.1 之前导出的宿主保留导出时
的图标，请重新执行导出并重建应用。模板自带中性图案；游戏需要自己的美术时，在导出
后替换图层位图即可。
