## 更新依赖

一起更新所有 dotzuki 依赖，使用 registry 版本 `0.10.1` 或 git tag `v0.10.1`。
主 workspace 与独立裸机 manifest 应使用同一发布版本，并刷新各自的 lockfile。
最低 Rust 版本仍为 1.88。

移除将 `dotzuki-engine-dsl` 重定向至本地副本的 Cargo patch 条目，前提是副本中
仅包含整数检查的临时修复。确认副本中没有其他改动后将其删除。
保留目标平台所需的其他依赖补丁。

## 保留静止 NPC 行为

此前使用分支专有 `update_npc_movement_with_policy_and_stationary` API 的消费者，
现在可以从发布版本使用该 API。保留游戏的回调及所选 `NpcWanderPolicy`。
回调在已有移动遍历中接收可见且空闲的静止 NPC；行走中或受脚本控制的 NPC 不进入回调。
已有移动入口不需要改动，并保留原有的静止 NPC 行为。

## 验证升级

使用更新后的 lockfile 编译 no_std 目标，并运行场景命令测试。
有效的 u8、u16 和 i16 边界仍被接受；小数、非有限值和越界参数仍被拒绝。
使用移动回调的消费者还应检查静止转向、游走延迟、脚本移动和 NPC 碰撞。

引擎 CI 在 `thumbv4t-none-eabi` 上关闭默认 feature 检查音频与 DSL 库。
仅用于宿主机的 DSL 编译器二进制不属于该裸机检查范围。
