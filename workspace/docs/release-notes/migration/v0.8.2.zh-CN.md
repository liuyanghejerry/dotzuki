将所有 `dotzuki-*` 依赖从 v0.8.1 更新到 v0.8.2。本版本没有破坏性的 Rust API
变更，只新增 trait 实现。

开始前，请阅读本补丁适用范围的[变更日志](../changelog.zh-CN.md)。

## 更新依赖

所有引擎 crate 应使用同一个版本。使用 registry 依赖时：

```toml
dotzuki-engine = "0.8.2"
dotzuki-mobile = "0.8.2"
```

使用 git 依赖时，把每个引擎依赖更新为 `tag = "v0.8.2"`，然后运行：

```bash
cargo update
```

## 对引擎状态做快照

引擎自身的运行时状态现在可序列化：DSL 解释器（`Interpreter`、`InterpState`）、
trigger manager、NPC 运行时状态、cutscene manager、连接过场、`CommandResult`、
`Metatile` 以及 overworld 演出状态实现 `Serialize` 与 `Deserialize`；DSL
`Interpreter` 还实现 `Debug` 与 `Clone`。

需要逐帧保存与恢复状态的游戏，可以直接对这些值派生快照类型；不必为每个引擎结构
另写镜像类型，也不必再固定一份私有引擎分支。
