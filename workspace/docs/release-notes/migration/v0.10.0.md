# Migrating to v0.10.0

> - **Audience**: rust developers
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.10.0

Update from v0.9.1 or the `fix/gba-psg-audio` branch while preserving consumer-owned game rules.
Before you start, read the [changelog](../changelog.md) and
[effect stack architecture](../../explanation/effect-stack.md).

## Update dependencies

Update all dotzuki dependencies together to registry version `0.10.0` or git tag `v0.10.0`.
Consumers pinned to `92ba95f` can replace that branch revision with the release tag after
testing their game. The minimum Rust version remains 1.88.
Consumers that skip v0.9.0 must also follow its [migration guide](v0.9.0.md) for removed UI APIs.

## Update NPC state adapters

`NpcRuntimeState::delay_counter` now uses `u16`. Widen typed `u8` assignments with
`u16::from(value)`; preserve values through 256 when writing saves.
Do not truncate this field back to `u8`. Audit binary serialization layouts and version
their save format when it stores the field at a fixed width.

The existing `update_npc_movement` entry point retains the default policy.
Use `update_npc_movement_with_policy` with `NpcWanderPolicy::Classic` for four equal
direction intervals, restricted-axis remapping, and a zero random delay interpreted as
256 frames. The choice belongs to the consuming game.

## Preserve battle action timing

`StackDriver::execute_turn_logged_with_before_action` invokes a consumer callback after
turn ordering and before each acting battler's forced-action resolution. The callback can
inspect the state left by the first actor and replace the current action, state, or effects.
A cancelled second actor does not invoke the callback. Existing turn entry points use no callback.

`EffectProvider::resolved_move` defaults to the selected move. Override it when a successful
`BeforeMove` gate resolves a called move. Ordering still uses the selected action; the
resolved move supplies the subsequent move pipeline and log entry. The status gate runs once.
Keep trainer decisions and game-specific called-move rules in the consumer.

## Connect bare-metal audio

Build `dotzuki-audio` without default features on a bare-metal target.
`Apu::set_register_sink` installs an optional register-write callback for the host's PSG
adapter. Accepted register writes continue to update the software APU.
The consumer supplies hardware-address translation and output timing.

Sparse track slots now retain their channel positions. Remove workarounds that compacted or
reindexed those slots. Test music, sound-effect completion, volume, panning, and pitch slides
on each supported backend; register-level tests do not replace hardware listening tests.

## Verify game behavior

Exercise trainer item/switch decisions before both actors, forced actions, a first-actor KO,
called moves, restricted-axis NPC wandering, zero-delay countdowns, and outward spiral
transitions. Games already using the branch hooks should retain their existing callbacks
and explicit classic policy when switching dependencies.
