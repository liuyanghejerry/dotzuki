把游戏从 v0.6.0 更新到 v0.7.0，并接入共用 Android 外壳。本版本没有破坏性的
Rust API 变更。

## 更新依赖

所有引擎 crate 应使用同一个版本。使用 registry 依赖时：

```toml
dotzuki-engine = "0.7.0"
dotzuki-mobile = "0.7.0"
```

使用 git 依赖时，把每个引擎依赖更新为 `tag = "v0.7.0"`，然后运行：

```bash
cargo update
```

## 接入 Android 导出

零 Rust 项目可以按 [Android 导出指南](../../how-to/export-android.zh-CN.md)
操作。自定义 Rust 游戏需要实现 `dotzuki_mobile::MobileGame`，通过
`export_mobile_abi!` 导出 ABI 版本 1，并执行：

```bash
python3 workspace/scripts/export-mobile-host.py \
  --platform android \
  --library /path/to/libmy_game_mobile.a \
  --init my-game:v1 \
  --out dist/android \
  --title "My Game" \
  --bundle com.example.mygame
```

生成的外壳接收不透明的初始化字节，其格式和校验由游戏工厂负责。
