# Migrating to v0.8.0

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.8.0

Update every `dotzuki-*` dependency from v0.7.1 to v0.8.0 and apply the
feature and public-type migrations below.

## Update dependencies

Keep all engine crates on one version. For registry dependencies:

```toml
dotzuki-engine = "0.8.0"
dotzuki-renderer = "0.8.0"
```

For git dependencies, update every engine entry to `tag = "v0.8.0"`, then run:

```bash
cargo update
```

## Enable APIs that moved behind features

`FrameBuffer::save_png` now requires the engine's `image` feature:

```toml
dotzuki-engine = { version = "0.8.0", features = ["image"] }
```

The default `dotzuki-engine-script` configuration still includes Boa. A
consumer that disables default features and uses `ScriptEngine`,
`ScriptApiRegistrar`, or other Boa-backed exports must enable `script-boa`:

```toml
dotzuki-engine-script = { version = "0.8.0", default-features = false, features = ["script-boa"] }
```

`dotzuki_renderer::mon_icon` now follows the renderer's resource-loading
boundary. A framebuffer-only consumer that uses this module must enable
`resource`:

```toml
dotzuki-renderer = { version = "0.8.0", default-features = false, features = ["resource"] }
```

## Migrate public hash-map values

Public engine and DSL structures now use deterministic, `no_std`-compatible
map and set aliases. Replace `std::collections` values passed into those APIs
with the aliases exported by the owning crate:

```rust
use dotzuki_engine::hash::HashMap;

let mut flags = HashMap::default();
flags.insert("opened_gate".to_owned(), true);
```

Use `dotzuki_engine_dsl::hash::{HashMap, HashSet}` for DSL AST values. Existing
maps can be converted with `into_iter().collect()` when ownership is available.

## Handle the `return` statement

`StoryStmt` has a new `Return` variant. Add a match arm in consumers that match
the enum exhaustively. The native interpreter and generated JavaScript both end
the current storyline when this variant runs. Do not persist or compare numeric
casts of `StoryStmt`: inserting `Return` changed the implicit discriminants of
the following `Assign` and `Command` variants.

## Update renderer type-sensitive code

The following `BattleEffects` methods now carry an inferred const storage
parameter so they accept packed and linear RGBA indexed framebuffers:

- `apply_enemy_hud_shake`
- `apply_screen_effects`
- `render_objects`
- `draw_substitute`
- `draw_minimized`
- `draw_squished`
- `draw_mon_rows`

Ordinary calls infer the parameter. Calls that supplied generic arguments with
turbofish syntax must include or allow inference for the new const argument.

`dotzuki_renderer::tile::Tile` now has four-byte alignment so GBA tile-copy
paths can issue aligned word loads. Remove `Tile` from downstream `repr(packed)`
structures; store it separately or use an aligned container.

## Choose indexed framebuffer storage

`IndexedFrameBuffer` and `RgbaIndexedFrameBuffer` remain packed by default on
every target. Existing packed-storage code can keep using `packed()` and
`packed_mut()`.

Use `LinearIndexedFrameBuffer` or `LinearRgbaIndexedFrameBuffer` when a platform
needs one byte per palette index, word alignment, `indices()`, or `indices_mut()`.
GBA Mode 4 consumers should use a linear alias for DMA-friendly presentation:

```rust
use dotzuki_renderer::LinearRgbaIndexedFrameBuffer;

let framebuffer = LinearRgbaIndexedFrameBuffer::default();
```

The storage choice is part of the type and no longer changes with the target.
