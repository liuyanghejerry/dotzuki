# 迁移至 v0.9.0

> 本文是 `release-notes/migration/v0.9.0.md` 的中文翻译，同步至引擎版本 v0.9.0
>（源文档 commit ce902be18620041f13dd89c66ffffb582dd44758）。

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.9.0

将消费方从 v0.8.2 升级，并在重新构建前替换已移除的 UI API。
开始前请阅读[变更日志](../changelog.zh-CN.md)，了解发布范围。

## 更新依赖与工具链

使用 Rust 1.88 或更新版本，并同步更新全部 `dotzuki-*` 依赖。
Registry 依赖的版本设为 `0.9.0`；git 依赖的 tag 设为 `v0.9.0`。
修改 manifest 后刷新消费方 lockfile。

## 替换已弃用的 UI 调用

将 `DialogConfig`、`FlexMenuConfig`、`YesNoConfig` 替换为
`dotzuki_engine::menu::MenuConfig`。将 `draw_dialog_legacy`、
`draw_flex_menu_legacy`、`draw_yes_no_legacy` 替换为对应的 `draw_dialog`、
`draw_flex_menu`、`draw_yes_no` 调用，传入 `MenuConfig` slice 和 `Ui`。
移除 flex-menu 旧 `EdgeInsets`、`Justify`、`SizeMode` 类型的 import。

处理 static layout `Context::set` 的 `Result`。容量耗尽时返回
`ContextCapacityError`；增大 const 容量或报告绑定失败。更新已有绑定会复用其槽位。

## 替换角色补丁与输入补救实现

使用 `OverworldActor::set_movement_speeds` 配置游戏的行走/跑步节奏，使用
`set_step_speed` 临时覆盖速度。速度必须为有限正数。传入 `None` 恢复配置的速度对；
变更会在下一次 update 生效，包括正在进行的步进。若整步必须保持固定节奏，请在
idle 时设置速度。默认速度保持每次 update 2/4 像素，动画节奏不变。

使用 `OverworldActor::nudge` 执行调用方驱动的像素偏移。它绕过碰撞检查，保留
目标 tile、朝向和行走状态。正在进行的步进会在下一次 update 继续朝原目标移动。

Web game shell 在浏览器和原生回退窗口中统一使用 `BufferedInput`。
移除消费方为缓存短按安装的重复键盘监听器。自定义循环可用 `set_button` 收集事件，
每次 simulation update 调用一次 `next_frame`，失焦时调用 `clear`。
两次 update 之间的多次短按会合并；它不是事件重放队列。

## 刷新导出的移动宿主

重新导出 Android 与 Harmony 宿主，以获得 runner 生命周期修复。
未声明 `mode` 的现有 autotile connection set 保持 cardinal 行为。
原生场景编辑器保留通用 runner 的渲染行为。
