# Migrating to v0.7.1

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.7.1

Update every `dotzuki-*` dependency from v0.7.0 to v0.7.1. This release has
no breaking Rust API changes.

## Update dependencies

Keep all engine crates on one version. For registry dependencies:

```toml
dotzuki-engine = "0.7.1"
dotzuki-mobile = "0.7.1"
```

For git dependencies, update every engine entry to `tag = "v0.7.1"`, then
run:

```bash
cargo update
```

## Android and HarmonyOS CLI exports

If you install `dotzuki` from crates.io and use `dotzuki export --android` or
`dotzuki export --harmony`, update to v0.7.1 before exporting. The release
package now includes the mobile ABI header that those generated projects need.
