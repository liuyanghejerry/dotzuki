从 v0.9.0 更新以采用共享横屏触控布局，无需修改 Rust API。
开始前，请阅读[变更日志](../changelog.zh-CN.md)了解发布范围。

## 更新依赖

一起更新所有 dotzuki 依赖：registry 依赖使用版本 `0.9.1`，
git 依赖使用 tag `v0.9.1`，然后刷新消费项目的 lockfile。
最低 Rust 版本仍为 1.88。

## 更新 Android 和 HarmonyOS 外壳

重新生成导出项前，备份自定义外壳改动。按照
[Android](../../how-to/export-android.zh-CN.md) 或
[HarmonyOS](../../how-to/export-harmonyos.zh-CN.md) 导出指南操作。
新外壳在完整游戏画面上叠加控件，并支持两个横屏方向。
现有八个输入位及移动端 ABI 版本 1 保持不变。

使用齿轮调整大小、位置、不透明度、左右交换、浮动移动和触觉反馈。
设置与存档分别持久化。请对照游戏的对话与选项菜单检查默认布局和镜像布局：
通用 ABI 不提供菜单边界，因此选项菜单仍可能与控件重叠。

## 接入 iOS 控件

按照[共享触控接入指南](../../../crates/dotzuki-mobile/controls/README.zh-CN.md)
添加可复用的 UIKit package。
消费游戏仍负责自己的 iOS 外壳、渲染、音频和生命周期。
每个游戏 tick 读取一次 `consumeInput()`，并与硬件输入合并；
编辑控件时暂停游戏，场景失焦时释放触控输入。
本版本不增加 iOS 导出器。

## 验证消费项目

检查移动与 A/B 同时输入、短按、两个横屏方向、前后台切换和设置持久化。
在目标设备上验证安全区与对话区的间距。
CI 覆盖共享输入逻辑和 UIKit 模拟器集成；
设备相关行为仍需在消费游戏支持的硬件上测试。
