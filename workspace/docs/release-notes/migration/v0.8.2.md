# Migrating to v0.8.2

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.8.2

Update every `dotzuki-*` dependency from v0.8.1 to v0.8.2. This release has
no breaking Rust API changes; it adds trait implementations.

Before you start, read the [changelog](../changelog.md) for this patch's
scope.

## Update dependencies

Keep all engine crates on one version. For registry dependencies:

```toml
dotzuki-engine = "0.8.2"
dotzuki-mobile = "0.8.2"
```

For git dependencies, update every engine entry to `tag = "v0.8.2"`, then
run:

```bash
cargo update
```

## Snapshot engine state

Runtime state owned by the engine is serializable: the DSL interpreter
(`Interpreter`, `InterpState`), the trigger manager, NPC runtime state, the
cutscene manager, connection transitions, `CommandResult`, `Metatile`, and
the overworld presentation states implement `Serialize` and `Deserialize`;
the DSL `Interpreter` also implements `Debug` and `Clone`.

Derive snapshot types over those values directly when a game saves and
restores frame-level state; no per-struct mirror type and no private engine
branch to pin.
