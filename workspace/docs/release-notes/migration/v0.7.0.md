# Migrating to v0.7.0

> - **Audience**: rust developers, game authors
> - **Type**: how-to
> - **Status**: active
> - **Last verified**: v0.7.0

Update a game from v0.6.0 to v0.7.0 and opt into the shared Android host.
This release has no breaking Rust API changes.

## Update dependencies

Keep all engine crates on one version. For registry dependencies:

```toml
dotzuki-engine = "0.7.0"
dotzuki-mobile = "0.7.0"
```

For git dependencies, update every engine entry to `tag = "v0.7.0"`, then run:

```bash
cargo update
```

## Adopt Android export

Zero-Rust projects can follow the
[Android export guide](../../how-to/export-android.md). A custom Rust game
implements `dotzuki_mobile::MobileGame`, exports ABI version 1 with
`export_mobile_abi!`, and calls:

```bash
python3 workspace/scripts/export-mobile-host.py \
  --platform android \
  --library /path/to/libmy_game_mobile.a \
  --init my-game:v1 \
  --out dist/android \
  --title "My Game" \
  --bundle com.example.mygame
```

The generated host accepts opaque initialization bytes, so the game factory
owns their format and validation.
