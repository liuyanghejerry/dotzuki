# Step 1.3 — `build.rs` Codegen

Mirror the existing trainer JSON → `trainer_data_gen.rs` codegen pattern in `crates/pokered-data/build.rs`. Read every `ui_layouts/*.json` file, emit a Rust file with `pub static SCREEN_LAYOUT: ScreenLayout = ScreenLayout { ... };` for each screen.

> **Cow output (post-momus B3 fix)**: All emitted string and slice fields use `Cow::Borrowed(...)`. This is zero-cost for `static` items (the borrow points at a `&'static str` literal or a `&'static [...]` array reference) and matches the runtime parser path which emits `Cow::Owned(...)`. Same type, same menu code, both paths.

## Reference Pattern

Read these first to mirror exactly:
- `crates/pokered-data/build.rs` — current `generate_trainer_data()` function
- `crates/pokered-data/trainers/*.json` — input shape
- `OUT_DIR/trainer_data_gen.rs` (after a build) — output shape

## What to Add to `build.rs`

```rust
// crates/pokered-data/build.rs (additions)

fn main() {
    // ... existing trainer/map codegen ...
    let manifest_dir = PathBuf::from(env::var("CARGO_MANIFEST_DIR").unwrap());
    let out_dir = env::var("OUT_DIR").unwrap();
    generate_ui_layouts(&manifest_dir, &out_dir);
}

fn generate_ui_layouts(manifest_dir: &Path, out_dir: &str) {
    let layouts_dir = manifest_dir.join("ui_layouts");
    println!("cargo:rerun-if-changed={}", layouts_dir.display());

    let out_path = Path::new(out_dir).join("ui_layouts_gen.rs");
    let mut out = String::new();

    out.push_str("// @generated by pokered-data/build.rs from ui_layouts/*.json — do not edit.\n");
    out.push_str("use std::borrow::Cow;\n\n");

    // 1. Collect all .json files
    let mut entries: Vec<_> = fs::read_dir(&layouts_dir)
        .unwrap_or_else(|e| panic!("read {}: {}", layouts_dir.display(), e))
        .filter_map(|e| e.ok())
        .filter(|e| e.path().extension().and_then(|s| s.to_str()) == Some("json"))
        .collect();
    entries.sort_by_key(|e| e.file_name());

    // 2. Parse each file and emit per-screen layout struct + static
    for entry in &entries {
        let json_path = entry.path();
        let content = fs::read_to_string(&json_path)
            .unwrap_or_else(|e| panic!("read {}: {}", json_path.display(), e));
        let parsed: serde_json::Value = serde_json::from_str(&content)
            .unwrap_or_else(|e| panic!("parse {}: {}", json_path.display(), e));

        // Validate schema_version
        let version = parsed.get("schema_version").and_then(|v| v.as_u64());
        if version != Some(1) {
            panic!("{}: schema_version must be 1, got {:?}", json_path.display(), version);
        }

        let screen = parsed["screen"].as_str()
            .unwrap_or_else(|| panic!("{}: missing `screen` field", json_path.display()));

        emit_screen_layout(&mut out, screen, &parsed["variants"]);
    }

    // 3. Emit a registry function for the wasm preview crate (raw embedded JSON)
    out.push_str("\npub fn get_layout_json(screen: &str) -> Option<&'static str> {\n");
    out.push_str("    match screen {\n");
    for entry in &entries {
        let stem = entry.path().file_stem().unwrap().to_string_lossy().into_owned();
        let json_str = fs::read_to_string(entry.path()).unwrap();
        // Embed raw JSON as &'static str for wasm preview to re-parse with schema flexibility
        out.push_str(&format!("        {:?} => Some({:?}),\n", stem, json_str));
    }
    out.push_str("        _ => None,\n    }\n}\n");

    fs::write(&out_path, out)
        .unwrap_or_else(|e| panic!("write {}: {}", out_path.display(), e));
}
```

## Emitting Cow Literals

The codegen functions that materialize struct values must wrap every string and slice in `Cow::Borrowed`:

```rust
fn emit_label(out: &mut String, label: &serde_json::Value) {
    let tx = label["tx"].as_u64().unwrap();
    let ty = label["ty"].as_u64().unwrap();
    let text = label["text"].as_str().unwrap();
    let color = emit_ink_color(&label["color"]);   // → "InkColor::Black"
    out.push_str(&format!(
        "LabelDef {{ tx: {tx}, ty: {ty}, text: Cow::Borrowed({text:?}), color: {color} }}"
    ));
}

fn emit_box(out: &mut String, box_def: &serde_json::Value) {
    let id = box_def["id"].as_str().unwrap();
    let rect = emit_tile_rect(&box_def["rect"]);
    let color = emit_ink_color(&box_def["color"]);

    out.push_str(&format!(
        "BoxDef {{ id: Cow::Borrowed({id:?}), rect: {rect}, color: {color}, "
    ));
    out.push_str("labels: Cow::Borrowed(&[");
    for (i, label) in box_def["labels"].as_array().unwrap().iter().enumerate() {
        if i > 0 { out.push_str(", "); }
        emit_label(out, label);
    }
    out.push_str("]), ");

    // dynamic_height is optional — emit None if absent, Some(DynamicHeight { ... }) if present
    match box_def.get("dynamic_height") {
        Some(dh) if !dh.is_null() => {
            let extra = dh["extra_per_row"].as_u64().expect("dynamic_height.extra_per_row must be u32");
            out.push_str(&format!(
                "dynamic_height: Some(DynamicHeight {{ extra_per_row: {extra} }}) "
            ));
        }
        _ => out.push_str("dynamic_height: None "),
    }

    out.push_str("}");
}
```

**Critical**: `Cow::Borrowed(&[...])` requires the slice literal to be a `&'static [LabelDef; N]` coerced to `&'static [LabelDef]`. Rust accepts this in `static` context because the array literal has static lifetime. Verify this compiles in a small standalone test before generating all layouts.

## Cow + `static` Verification

Before generating all layouts, write a 10-line standalone smoke test (delete after passing) to confirm `Cow::Borrowed(&[...])` works in `static` context:

```rust
// crates/pokered-data/src/ui_layout/cow_smoke.rs (TEMPORARY)
use std::borrow::Cow;
struct Item { text: Cow<'static, str> }
struct Box  { items: Cow<'static, [Item]> }
static B: Box = Box {
    items: Cow::Borrowed(&[
        Item { text: Cow::Borrowed("hi") },
    ]),
};
#[test] fn it_compiles() { let _ = &B; }
```

If this fails to compile, the codegen approach must change (e.g., use `&'static [Item]` for the items field instead of `Cow`, sacrificing runtime-parser symmetry for that specific field). Resolve before writing the codegen.

## Validation in build.rs

`build.rs` must reject malformed JSON with **clear error messages** including the file path and the offending field. Examples:
- Missing `schema_version` → "ui_layouts/foo.json: schema_version must be 1, got null"
- Unknown `kind` for primitive → "ui_layouts/stats.json: variants.page1.primitives[2]: unknown kind 'wibble'"
- `parent_id` references nonexistent box/region → "ui_layouts/stats.json: variants.page1.primitives[1]: parent_id 'no_such_box' not found"
- Duplicate `id` within a variant → "ui_layouts/mart.json: variants.main_menu: duplicate id 'menu_box'"

`build.rs` failures must `panic!()` so cargo build fails — never silently emit broken Rust.

## Why Embed Raw JSON Strings

The `get_layout_json(screen) -> Option<&'static str>` function is for the **wasm preview crate** (Stage 2). The preview re-parses the JSON because:
- Editor sends modified JSON via `set_layout(json)` — preview must parse arbitrary editor JSON anyway
- Default-state preview re-parses the embedded JSON (single code path)
- Both paths share the same `serde_json::from_str::<MartLayout>(json)` call → fewer divergence bugs

The game itself uses the typed statics directly (zero runtime parsing). Stage 2 wasm preview pays the parse cost once per `set_layout` call.
